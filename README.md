# 🌸 Iris Neural Network

Простая нейронная сеть на **Python**, реализованная с использованием **NumPy** без применения готовых ML-фреймворков для обучения.

Программа обучает нейронную сеть классифицировать цветы из датасета **Iris** по четырём признакам и определять один из трёх видов:

- **Setosa**
- **Versicolor**
- **Virginica**

В проекте вручную реализованы основные этапы работы нейронной сети: прямое распространение, функции активации, вычисление ошибки, обратное распространение и обновление весов.

## 📌 Возможности

Программа позволяет:

- загружать стандартный датасет Iris;
- обучать простую полносвязную нейронную сеть;
- классифицировать цветы по четырём признакам;
- получать вероятность принадлежности к каждому классу;
- рассчитывать точность модели;
- строить график изменения ошибки во время обучения.

## 🧠 Архитектура нейронной сети

Используется простая полносвязная нейронная сеть:

```text
Входной слой
4 нейрона
    │
    ▼
Скрытый слой
10 нейронов + ReLU
    │
    ▼
Выходной слой
3 нейрона + Softmax
    │
    ▼
Setosa / Versicolor / Virginica
```

### Входной слой

На вход передаются четыре характеристики цветка:

1. Длина чашелистика (`sepal length`)
2. Ширина чашелистика (`sepal width`)
3. Длина лепестка (`petal length`)
4. Ширина лепестка (`petal width`)

Поэтому размер входного слоя равен:

```python
INPUT_DIM = 4
```

### Скрытый слой

Скрытый слой содержит 10 нейронов:

```python
H_DIM = 10
```

В качестве функции активации используется **ReLU**:

```python
def relu(t):
    return np.maximum(t, 0)
```

### Выходной слой

Выходной слой содержит три нейрона — по одному на каждый класс:

```python
OUT_DIM = 3
```

Для получения вероятностей используется функция **Softmax**.

Например:

```text
Setosa:     95.2%
Versicolor:  3.8%
Virginica:   1.0%
```

В качестве результата выбирается класс с максимальной вероятностью.

| Признак | Описание |

| Sepal Width | Ширина чашелистика |

| Petal Width | Ширина лепестка |

Всего существует три класса:

| Класс | Код |
|---|---:|
| Setosa | 0 |
| Versicolor | 1 |

## 🔄 Процесс обучения

Обучение нейронной сети состоит из нескольких этапов.

### 1. Инициализация

Создаются случайные веса и смещения:

```python
W1
b1
W2
b2
```

После этого значения нормализуются для улучшения сходимости обучения.

### 2. Формирование мини-батча

Датасет перемешивается перед каждой эпохой, после чего данные обрабатываются небольшими группами.

Размер батча:

```python
BATCH_SIZE = 50
```

### 3. Прямое распространение

Входные данные проходят через сеть:

```text
X
 ↓
X × W1 + b1
 ↓
ReLU
 ↓
H × W2 + b2
 ↓
Softmax
 ↓
Вероятности классов
```

### 4. Вычисление ошибки

Для оценки ошибки используется **Sparse Cross Entropy**:

```python
def sparse_cross_entropy(z, y):
    return -np.log(z[0, y])
```

Чем выше вероятность правильного класса, тем меньше ошибка.

### 5. Обратное распространение

С помощью **backpropagation** вычисляются градиенты весов и смещений.

Полученные градиенты используются для корректировки параметров нейронной сети.

### 6. Обновление весов

Параметры обновляются с использованием скорости обучения:

```python
ALPHA = 0.001
```

Например:

```python
W1 -= ALPHA * dE_dW1
```

Таким образом сеть постепенно изменяет свои веса, чтобы уменьшить ошибку классификации.

## 📊 График ошибки

Во время обучения значение ошибки каждой итерации сохраняется в массив:

```python
loss_arr = []
```

После завершения обучения строится график:

```python
plt.plot(loss_arr)
```

По графику можно оценить процесс обучения модели.

Если обучение проходит успешно, ошибка в целом должна уменьшаться по мере обучения.

## 🔍 Классификация собственного цветка

Для классификации используется функция:

```python
classify_flower(features)
```

Ей необходимо передать четыре признака:

```python
features = [
    sepal_length,
    sepal_width,
    petal_length,
    petal_width
]
```

Например:

```python
features = [5.0, 3.4, 1.5, 0.2]

predicted_class, probabilities = classify_flower(features)

print(predicted_class)
print(probabilities)
```

Результатом будет название предполагаемого класса и вероятности для всех трёх классов.
